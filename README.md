# Jardim_Doce

Jogo de navegador em HTML/JavaScript, pronto para deploy em Vercel como site estático.

## Deploy no Vercel

1. Faça push deste repositório para o GitHub.
2. Acesse o painel do Vercel e importe o projeto.
3. Use a configuração padrão de projeto estático.
4. O arquivo `index.html` na raiz já é o ponto de entrada e o `vercel.json` garante o roteamento correto.

## Como executar localmente

Abra o arquivo `index.html` em um navegador ou use um servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
