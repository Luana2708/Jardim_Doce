# Missão Espacial

Jogo em HTML5/JavaScript de plataforma 2D com menu, níveis, coleta de itens e objetivo final.

## Deploy no Vercel

Este projeto é um site estático, então ele já pode ser publicado no Vercel sem build step.

### Opção recomendada
- Conecte este repositório ao Vercel
- Na configuração do projeto, defina a pasta raiz como `Miss-o_espacial`
- O arquivo `index.html` será usado automaticamente

### Arquivos importantes
- `index.html` — lógica do jogo e layout
- `vercel.json` — configuração do deploy estático

### Observações
- Não há dependências externas ou instalação obrigatória
- O jogo funciona em navegador moderno e em dispositivos desktop/mobile
